# Open an analyst review

Read CLAUDE.md and docs/cli.md. Confirm workspace and requested scope.

```bash
node scripts/logs.mjs open-case --code="LOG-301" --title="Review" --owner="Owner" --due=2027-01-31 --by="Operator"
```

Use the requested case code, owner and due date. Do not create a case solely from an unverified attack claim.

Answer from the actual output. Include the evidence scope and the next review action. Never send, publish, disable accounts or change external systems.
