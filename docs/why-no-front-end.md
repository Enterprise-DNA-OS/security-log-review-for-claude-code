# Views without a front end

The daily review is a set of questions over events and case records. The CLI answers them, and read-only branded HTML supplies coverage, administrative activity, policy checks and investigation packs. /new-view adds another read-only query; /customise changes fields or rules through a migration.

A screen provides interactive filtering, clickable event timelines, continuous streaming updates and mobile navigation. This base does not provide those. It reviews batch imports and records analyst work. Existing collectors and alerts remain in place until their replacements are separately delivered and validated. If your team needs a screen, Enterprise DNA builds it as part of your version.

Reports contain private evidence. Open them locally or through an access-controlled internal surface. They are not public website pages and have no action buttons. No report sends an email or changes an external system.
